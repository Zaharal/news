# Новостной раздел с админкой, пользователями и правами доступа

Проект на чистом Node.js - **никаких зависимостей ставить не нужно** (нет npm install, нет package.json).
Данные хранятся в JSON-файлах в папке `data/` (создаются автоматически при первом запуске).

## Запуск

```
node server.js
```

Открыть в браузере: http://localhost:3000

## Учётные записи (создаются при первом запуске)

| Логин  | Пароль | Права |
|--------|--------|-------|
| admin  | admin  | Новости + управление пользователями |
| editor | editor | Только закрытый раздел (новости) |

## Что где

- **Публичная часть** — главная `/`: список новостей (заголовок, анонс, превью).
  Клик по заголовку → детальная страница с полным текстом, картинкой, заголовком и автором + ссылка «вернуться к списку».
- **Закрытая часть** — `/panel` (после входа): добавление, редактирование и удаление новостей.
  При редактировании текста используется WYSIWYG-редактор (жирный, курсив, подчёркнутый, заголовки, списки, ссылки).
- **Административная часть** — `/users` (только для роли «Администратор»): добавление, изменение и удаление пользователей, настройка прав доступа.
  Самостоятельной регистрации нет — пользователей создаёт только администратор.

## Поля пользователя

Логин, Пароль (хранится в виде sha256-хеша), ФИО, Имейл, Дата последней авторизации, Дата регистрации.

## Как устроено (коротко)

- `server.js` — весь сервер: маршруты, HTML-шаблоны, работа с данными.
- Сессии: после входа выдаётся cookie `sid`, соответствие «sid → пользователь» хранится в памяти сервера.
- Права: роль `editor` пускает только в `/panel`, роль `admin` — ещё и в `/users`.
